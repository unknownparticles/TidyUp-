# 收纳整理师 - 货柜消除 3D (Goods Sort Game)

参考经典货柜收纳与 3 消益智游戏制作的精美 Web 版游戏。

## 🌟 游戏核心机制

1. **3 消匹配消除**：
   - 将 **3 个完全相同的物品** 移动到同一个货柜格子或传送货架中即可完成配对消除。
   - 触发高分连击、星星粒子飞溅与清脆消除音效。

2. **空间与前后遮挡层级机制**：
   - 上方为主要操作柜（9 个大格，每格可容纳 3 个物品），下方为 3 行自动滚动的备选传送货架。
   - **前后深度遮挡**：前排物品被移走或消除后，后排被遮挡的物品（**灰色状态**）将立即激活移到前排并展现绚丽色彩，可被抓取。

3. **下方三行传送货架自动滚动**：
   - 下方 3 行迷你货架呈交替方向横向自动滚动。
   - 带有留白空格，玩家可利用空格进行灵活的中转周转。

4. **四大辅助道具**：
   - 🔨 **锤子 (19)**：强制消除任意指定的单个物品，解除卡手障碍。
   - 🪄 **魔棒 (41)**：自动在全场中寻找并配对消除一组 3 消物品。
   - ❄️ **冰冻 (67)**：暂停倒计时与减速，获得宝贵思考时间。
   - 🔄 **重排 (+)**：打乱并重新排列当前可见的物品位置，化解死局。

5. **音效与视觉**：
   - 基于 Web Audio API 自研纯原生合成音效（点击、拾取、放置、消除和弦、锤击碎裂、魔棒魔法、冰冻寒芒、通关号角）。
   - Canvas 物理粒子引擎，支持星星爆破与彩带飞舞。

## ⚙️ GitHub Pages 部署说明

本项目采用纯原生前端技术构建（HTML5 + CSS3 + 原生 JavaScript + Web Audio API + Canvas），无须打包构建，天然支持各类静态托管：

1. **GitHub Actions 自动部署（已配置）**：
   - 仓库内已包含 `.github/workflows/deploy.yml`。
   - 提交代码到 `main` 分支将自动触发构建并部署至 GitHub Pages。
   - 在 GitHub 仓库设置 `Settings -> Pages -> Build and deployment -> Source` 选择 **GitHub Actions** 即可。

2. **分支根目录直接托管（备选方案）**：
   - 也可在 `Settings -> Pages -> Build and deployment -> Source` 选择 **Deploy from a branch**。
   - 分支选择 `main`，目录选择 `/ (root)`，保存后即生效。

## 🏷️ 版本规范与自动递增

游戏在点击右下角 **暂停** 按钮时，弹窗顶部会清晰展示当前游戏版本号（例如 `版本号：v1.1.0`）。

### 版本号自增规范
- 🚀 **大功能**：大版本号 +1（Major +1，例如 `1.1.0` -> `2.0.0`），执行：
  ```bash
  npm run bump:major
  ```
- ✨ **小功能**：小版本号 +1（Minor +1，例如 `1.0.0` -> `1.1.0`），执行：
  ```bash
  npm run bump:minor
  ```
- 🐞 **修复优化**：补丁号 +1（Patch +1，例如 `1.1.0` -> `1.1.1`），执行：
  ```bash
  npm run bump:patch
  ```

## 🎨 物品照片与木色货架

当前物品库采用用户提供的 186 张物品照片，保留原图造型、材质和颜色。素材位于 `assets/items/photos/`，物品编号与原始文件名对应。页面直接使用项目内素材，运行时不依赖下载目录。

- **透明背景**：仅去除与图片外边缘连通的近白背景，保留主体内部的白色衣料、眼睛与标签。
- **图片压缩**：全部在用照片采用 WebP（质量 82），保留 `200 × 280` 尺寸与无损透明通道。导入脚本直接输出压缩素材；历史 PNG 参考图使用无损压缩。可运行 `npm run compress:items` 重新压缩。
- **统一尺寸**：照片等比裁切并居中放入 `200 × 280` 透明画布，主体限制在 `184 × 248` 区域并统一底部对齐。柜格、滚动货架与拖拽预览使用相同尺寸。
- **物品目录**：`assets/items/items_data.json`、`src/items.js` 与独立运行的 `app.js` 同步使用完整照片物品库。关卡按物品类别选择，保留前后层、三消与拖拽机制。
- **木纹柜格**：`assets/ui/cabinet_wood.jpg` 使用参考图无遮挡的木纹柜格行组成完整九宫格，去除原图顶部头像和计时栏。
- **界面配色**：参考图中的橘猫头像、深蓝紫顶栏、金黄色工具按钮与实木底栏用于统一界面。`assets/ui/cat_avatar.webp` 与 `assets/ui/toolbar_wood.webp` 从参考图裁切，游戏区域保留白色背景。弹窗按钮同步使用木色。
- **紧凑排列**：柜格与底部浮板内的物品居中紧排，取消均分空隙，相邻物品轻微靠拢；物品与拖拽预览维持统一尺寸。
- **底部浮板**：`assets/ui/shelf_wood.png` 使用提供的木色浮板，按原图比例显示厚度，宽度随三个物品位置计算，仅留两侧 2 像素木边；物品站在浮板上缘，三行继续交替横向滚动。
- **离线资源**：版本化缓存同步更新物品与木纹背景，完整照片物品库在首次在线加载后预缓存供离线关卡使用。

重新导入照片需要 Python 3 与 Pillow：

```bash
python3 -m pip install -r scripts/requirements-assets.txt
npm run import:items -- /照片目录
npm run bump:minor
```

原几何 SVG 与 `generate:svg` 命令保留作历史素材方案；执行该命令会将物品目录恢复为旧的几何物品。

> 💡 **Git Hook 自动化**：已配置 `.githooks/pre-commit`。每次提交代码时，若未手动修改版本号，提交钩子将自动按小功能规则递增小版本号并同步更新 `package.json`、`app.js` 与 `index.html`。若为大功能提交，可提前运行 `npm run bump:major` 或使用 `BUMP=major git commit -m "..."`。
